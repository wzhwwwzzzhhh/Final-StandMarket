# Phase 3: 支付网关 — 支付宝沙箱接入

> 基于主计划 [功能拓展主计划.md](功能拓展主计划.md) Phase 3
> 日期: 2026-07-18

## 步骤

### Step 1: 数据库 — 创建 payment 表

SQL 保存在 `mysql/payment_table.sql`

### Step 2: Maven 依赖 — 添加支付宝 SDK

修改 `backend/fashion-server/pom.xml`，添加 `alipay-sdk-java 4.38.10.ALL`

### Step 3: 配置 — 添加支付宝沙箱参数

- `application.yml` — 添加 `fashion.alipay.*` 占位符
- `application-dev.yml` — 填写沙箱实际值（app-id、app-private-key、alipay-public-key、gateway-url、notify-url、return-url）

### Step 4: 后端 — AlipayConfig 配置类

提供 `@ConfigurationProperties(prefix = "fashion.alipay")` + `AlipayClient` Bean

### Step 5: 后端 — PaymentController.java

用户端支付控制器：
- `POST /user/pay/alipay/{orderId}` — 创建支付宝支付，返回支付表单 HTML
- `GET /user/pay/status/{orderId}` — 查询支付状态
- `POST /user/pay/alipay/verify` — 支付宝同步回跳验签更新订单

### Step 6: 后端 — PayNotifyController.java

异步回调通知（不加 `/user` 前缀，绕过登录拦截器）：
- `POST /notify/paySuccess` — 验签 + 更新支付记录 + 更新订单状态

### Step 7: 后端 — 修改 PaymentService + OrderService

新增 `updatePaySuccess()` 方法，供回调使用。

### Step 8: 前端 — 支付 API + 结果页

- `frontend/fashion-client/src/api/payment.js` — 新增 API 模块
- `frontend/fashion-client/src/views/PayResult.vue` — 支付结果页（含验签、自动重试、刷新按钮）
- `frontend/fashion-client/src/router/index.js` — 添加 `/pay/result` 路由

### Step 9: 前端 — 修改 Order.vue

`handlePay()` 根据 `payMethod` 判断：
- 支付宝（payMethod=2）→ 调后端获取 form → 动态提交跳转沙箱
- 微信（payMethod=1）→ 保持原有 mock 逻辑

## 代码审查报告

> 审查日期: 2026-07-18

### 发现的问题及修复

| # | 严重度 | 问题 | 修复方式 |
|---|--------|------|---------|
| 1 | 🔴 Critical | `trade_no` 未持久化，无法关联支付宝交易 | Payment 实体 + Mapper + XML + SQL 添加 trade_no 字段 |
| 2 | 🔴 Critical | 异步回调幂等性检查 `== 2` 应改为 `!= 0`，防止已失败的记录被重处理 | PayNotifyController 已修改 |
| 3 | 🟡 Important | `returnUrl` 拼接用 `?` 固定，如 URL 已有参数会生成非法地址 | 改为判断 `contains("?")` 动态选择 `?` 或 `&` |
| 4 | 🟡 Important | BizContent JSON 字符串拼接，特殊字符会破坏 JSON | 当前 order number 格式安全，暂未修复（标记为潜在风险） |
| 5 | 🟡 Important | 异步回调缺少 `app_id` 校验 | PayNotifyController 已添加 |
| 6 | 🟡 Important | Payment 和 Order 更新不在同一事务，存在部分失败风险 | 新增 `OrderService.handlePayCallback()` 统一事务处理 |
| 7 | 🟡 Important | PayResult.vue 的 setTimeout 未在组件卸载时清理 | 添加 `beforeUnmount` 清除定时器 |

### 已确认正常项

- `Enumeration` 替代 `Iterator` 正确（Java 8 兼容）
- `@/utils/request` 导入路径正确
- YAML 块标量格式的 `app-private-key` 与 Alipay SDK 兼容
