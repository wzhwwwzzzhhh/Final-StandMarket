# 用户端个人中心视觉优化

> 关联主计划 [功能拓展主计划.md](功能拓展主计划.md) 的 Phase 8
> 日期：2026-07-19

## 目标

将用户端个人中心从浅色圆角卡片风格统一为 STAND/MARKET 的深色街头机能风，并保持资料展示、订单跳转、服务入口、推荐商品与退出登录逻辑不变。

## 实施步骤

1. 重构顶部档案背景与用户资料卡，突出身份信息和统计数据。
2. 将订单状态与服务入口统一为深色可交互网格。
3. 统一推荐商品与退出操作的视觉反馈，补充窄屏响应式布局。
4. 审查页面模板、样式和现有跳转逻辑，并做单文件编译验证。

## 涉及文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `frontend/fashion-client/src/views/Profile.vue` | 修改 | 重构个人中心模板局部结构与 scoped 样式，不修改数据接口和跳转方法。 |

## 验收标准

- 用户资料、订单、服务、推荐和退出入口保持可用。
- 页面不再出现与全站风格冲突的大面积浅色卡片与蓝紫渐变。
- 桌面端和移动端均保持清晰的层级与可操作性。

## 审查报告

### 验证与审查（2026-07-19）

- 已通过浏览器刷新与截图复核：个人中心资料区、订单区、服务区、推荐区和退出入口均成功渲染为深色机能风。
- `Profile.vue` 模板与 scoped CSS 单文件编译通过，`git diff --check` 无空白错误。
- 审查确认资料编辑、订单筛选、地址/收藏/优惠券入口、商品详情跳转、收藏数加载与退出登录逻辑均未改变。
- 审查发现的超窄屏统计栏溢出风险已修复：400px 以下使用三等分网格并隐藏分隔线；未实现的头像相机入口已移除，避免错误交互暗示。
- 全量生产构建未重试：上一阶段已确认它受未涉及的 `ProductDetail.vue` 既有 CSS 语法错误阻塞。
