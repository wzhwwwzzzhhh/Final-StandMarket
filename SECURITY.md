# Security policy

## Report a vulnerability

Do not disclose credentials, personal data, payment parameters, exploitable details, or proof-of-concept payloads in a public Issue.

Use [GitHub private vulnerability reporting](https://github.com/wzhwwwzzzhhh/Final-StandMarket/security/advisories/new). If the private form is temporarily inaccessible, contact the repository owner without sending exploit details; do not fall back to a public Issue.

Include privately:

- affected component and version/commit;
- impact and required preconditions;
- minimal reproduction steps;
- redacted evidence;
- suggested mitigation when known.

Never include real passwords, JWTs, API keys, payment keys, production database data, or unredacted user information.

## Response expectations

The maintainer will first confirm receipt and severity, then coordinate remediation and disclosure timing. A report is not considered resolved until affected credentials are rotated where necessary and the fix has verification evidence.
